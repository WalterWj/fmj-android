## 1. 游戏概述

**伏魔记** 是一款基于Java开发的中国风RPG游戏，采用自定义字节码脚本系统驱动剧情发展。

- **引擎**: Java桌面RPG引擎 (模拟Android graphics API)
- **资源打包**: 所有游戏资源打包在 `DAT.LIB` 二进制文件中
- **资源总数**: 1227个资源 (186个脚本, 83张地图, 216个物品, 107个魔法, 63个怪物, 34个NPC, 3个玩家角色)
- **脚本系统**: 基于字节码的脚本解释器，包含68+种命令处理器
- **事件系统**: 2400个全局事件标志位, 240个变量
- **编码**: 所有中文文本使用GBK编码存储

**游戏起始**: `startChapter(1, 1)` -- 从第1章第1节开始

## 3. 主线剧情流程

### 序章: 无机道人与赤血天魔 (t1i1)

游戏开场动画：二十年前，无机道人与赤血天魔(赤血)决战，无机道人获胜后将赤血封印。赤血临走前留下一颗魔种。二十年后，柳清风在三清宫长大成人。

**关键脚本**: t1i1 (游戏序章), t1i5 (无机除心魔、混元金斗放置伏魔洞)

### 第一章: 三清宫 (t2i1 - t2i52)

#### 1.1 取伏魔剑下山 (t2i2)
- 师父无机道人命柳清风取伏魔剑下山
- 获得：暗器x21, 暗器x19
- **GAME OVER条件**: 某些错误选择会导致游戏结束

#### 1.2 伏魔洞取剑 (t2i18)
- 进入伏魔洞取伏魔剑
- 遭遇**护剑神** (Lv5 HP1600 ATK100) 战斗
- **选择分支**: "免战" / "欠扁"
- 获得伏魔剑

#### 1.3 灯洞1-8任务 (t2i19 - t2i26)
- 共8个灯洞任务，依次完成点亮伏魔灯
- 各洞中有护灯兽 (Lv3 HP420) 等怪物

#### 1.4 摩天顶四象诛仙阵 (t2i32)
- 在摩天顶遭遇四象诛仙阵
- 需要使用四象之精(苍龙/白虎/朱雀/玄武)破阵
- **选择分支**: "取消" / "使用苍龙之精"等
- 需天心灯护体才能安全通过

#### 1.5 观星亭 (t2i33)
- 使用万能钥匙进入观星亭
- 获得**无机乾坤剑** (剧情物品)
- **选择分支**: "取消" / "使用万能钥匙"

#### 1.6 愚人居支线 (t2i52)
- 遭遇通宵虫、不点点、南方小鬼三人
- 三张神秘卡片的选择：
  - 通宵虫卡片: "不给" -> 战斗 / "奉还" -> 学会魔法百虫欺天
  - 不点点卡片: "不给" -> 战斗 / "交出" -> 可交换装备
  - 南方小鬼卡片: "不给" -> 战斗 / "奉还"
- **可错过**: 给卡片学会百虫欺天 vs 不给卡片换装备芦藤雌甲

### 第二章: 忘忧村 (t3i1 - t3i13)

#### 2.1 蛇妖危机 (t3i1 - t3i5)
- 忘忧村遭遇蛇妖男 (Lv10 HP4400) 绑架孩童
- 蔡大妈等村民求助
- 慕容玄家与毒瘴林入口探索

#### 2.2 慕容小梅加入 (t3i8)
- 救出慕容小梅后加入队伍
- 学习新魔法

#### 2.3 毒瘴林/蛇窟 (t4i1 - t4i10)
- 进入毒瘴林，需要防毒装备
- 蛇窟山洞探索
- 获得多种装备和道具

### 第三章: 石梦城 (t5i1 - t5i21)

#### 3.1 李虎事件 (t5i1, t5i15)
- 石梦城遭遇李虎 (Lv7 HP2000) 欺压百姓
- 与李虎战斗
- **选择分支**: 使用万能钥匙进入李虎家

#### 3.2 老王事件 (t5i18)
- 遭遇老王 (Lv7 HP1600)
- **选择分支**: "放走" / "杀死"
  - 放走 -> 老王说住石梦城可找他
  - 杀死 -> 战斗

#### 3.3 鲁斧与芦藤甲 (t5i11)
- 鲁斧打造芦藤甲
- 获得芦藤雌甲/雄甲 (避毒装备)

#### 3.4 赤血再次出现 (t5i13)
- 赤血在石梦城现身
- 获得多种物品

### 第四章: 原野/钟山 (t6i1 - t6i14)

#### 4.1 原野阡陌 (t6i1 - t6i9)
- 在原野阡、原野陌等地图穿行
- 遭遇打手、飞龙腿、无赖飞锤等杂兵
- 多条岔路迷宫

#### 4.2 转折路口 (t6i10 - t6i14)
- 到达转折路口
- 前往建业城方向

### 第五章: 建业城 (t7i1 - t7i14)

#### 5.1 游人钱袋 (t7i1)
- 遇到游人丢失钱袋
- **选择分支**: "不给" (战斗赢250文) / "奉还" (什么都没有)
- 获得万能钥匙

#### 5.2 阿军与老孟情书 (t7i9)
- 传递老孟情书给阿军
- 获得金色钥匙
- 学习新魔法

#### 5.3 袁萍芷相关 (t7i14)
- 袁萍芷线索

### 第六章: 钟山道院 (t8i1 - t8i12)

#### 6.1 冲虚道人 (t8i1)
- 到达钟山道院
- 遭遇冲虚道人
- 章节跳转至第7章

#### 6.2 霸王钟 (t8i3 - t8i9)
- 霸王钟事件
- 赤血抢走霸王钟
- **选择分支**: 在钟山道院的关键选择
- 获得多种装备和道具
- 学习魔法

#### 6.3 赤血大战 (t8i11 - t8i12)
- 与赤血 (Lv24 HP8000 ATK320) 大战
- 赤血逃走，霸王钟被抢
- 学习新魔法

### 第七章: 白水镇 (t9i1 - t9i14)

#### 7.1 白水镇怪事 (t9i1)
- 镇上每天有孩童失踪
- 老宅夜有妇人哭声
- 游人疯癫 (赤血摄魂术受害者)
- **选择分支**: 使用万能钥匙进入

#### 7.2 老宅救援 (t9i2 - t9i11)
- 进入老宅探索
- 发现枯井迷宫
- 寻找失踪的袁萍芷

#### 7.3 摄魂阵 (t9i13)
- 赤血设下**摄魂阵** (七大邪阵之一)
- 八卦方位有倒埋孕妇尸体，可幻化为妖怪 (怨妇幻妖1-8)
- 破阵方法：将倒埋尸体掘出放正
- 赤血大战
- **袁萍芷加入队伍**
- 慕容小梅、袁萍芷加入队列

#### 7.4 镇长告别 (t9i14)
- 镇长告知有人带着大钟(霸王钟)往北走
- 章节跳转

### 第八章: 南北村 (t10i1 - t10i9)

#### 8.1 周处庙 (t10i1 - t10i2)
- 南北村是周公(周处)的故乡
- 周处推算南山白虎和北海苍龙有复活之象
- 白虎醒风导致村民昏迷
- 周处给无忧丹救治村民
- 获得周处除三害(物品)

#### 8.2 村中设施 (t10i3 - t10i9)
- 武器店、杂货店、药店、皮皮家、民宅、小客栈

### 第九章: 酆都鬼城 (t11i1 - t11i10)

#### 9.1 鬼城探索 (t11i1)
- 酆都城人鬼分治：人占白天，鬼占黑夜
- 最近鬼白天也出来，因天下群魔复活骚扰鬼族
- 客栈住店后可夜间外出

#### 9.2 鬼王 (t11i10)
- 城隍庙见鬼王
- 与白无常战斗
- 鬼王告知霸王钟被魔族抢走，天道(五斗米道掌教)所为
- 天道在鹤鸣山
- 鬼王因恼怒天道对所有道士恨之入骨，但最终合作

### 第十章: 南山白虎 (t12i1 - t12i3)

#### 10.1 南山入口 (t12i1)
- 腥臭味扑鼻

#### 10.2 南山迷宫 (t12i2)
- 遭遇伥鬼战斗
- 章节跳转至第13章(北海)
- **GAME OVER条件**: 某些错误选择

#### 10.3 南山虎穴 (t12i3)
- 白虎 (Lv28 HP12000 ATK520) 变成草堆逃跑
- 白虎战斗：白虎使用腥风魔功
- 获得白虎之精
- 学习魔法

### 第十一章: 北海苍龙 (t13i1 - t13i2)

#### 11.1 北海入口 (t13i1)
- 血红的水，无生机
- 战斗：恶鱼、章鱼、贝壳、血云雾
- 获得苍龙之精
- 学习魔法

#### 11.2 北海龙潭 (t13i2)
- 蛟护院 (Lv20 HP3200) 和 蛇护院 (Lv22 HP3600)
- 先分别战斗，后合体战斗
- 苍龙 (Lv30 HP14000 ATK420) 使用血雨大法
- 获得苍龙之精

### 第十二章: 鹤鸣山/最终章 (t14i1 - t14i11)

#### 12.1 鹤鸣山脚 (t14i1)
- 村庄被魔族祸害
- 村民恐惧

#### 12.2 四象阵通过 (t14i2 - t14i7)
- 横桥、竖桥、台子等地图
- 四象之精破阵
- 获得玄武之精
- 遭遇小怪战斗

#### 12.3 鹤鸣山洞口 (t14i8)
- 关键剧情揭示：
  - 天道(五斗米道掌教)无法一统魔神人三界
  - **朱雀(袁萍芷)真实身份曝光**：四象星君之一，被无机解除封印后布下四象诛仙阵
  - 无机才是真正的幕后黑手：修炼万魔幻化到第7层，利用柳清风解除群魔封印
  - 天道只是借力使力抢霸王钟
  - 朱雀被周处点化弃恶向善
  - 需三天内赶到三清宫除无机
- **选择分支** (t14i8 @addr=128): 招募/拒绝天道
  - 天道邀请柳清风加入 -> 拒绝 -> 天道大笑后死去
  - 朱雀(袁萍芷)自杀，传授"妙手空空"魔法
- 天道战斗 (天道 Lv33 HP20000 ATK400)

#### 12.4 天师陵墓 (t14i9 - t14i10)
- 玄武 (Lv34 HP18000 ATK420 DEF700) 战斗
- 获得玄武之精
- 天师精魄 (张道陵魂魄) 帮助解脱
- 告知无机已修炼万魔幻化第十层(将万物幻化为魔，不死之身)
- 天师魂魄将众人传送到忘忧村附近

#### 12.5 最终决战 (t14i11)
- 回到三清宫面对无机
- **选择分支** (t14i11 @addr=444): 最终选择
- **GAME OVER条件**: 某些选择导致游戏结束
- 章节跳转至结局

## 9. 可错过内容警告

### 9.1 通宵虫卡片 (t2i52) -- 可永久错过

**位置**: 愚人居 (t1i31)
**NPC**: 通宵虫 (t2i32)
**选择**: 给卡片 / 不给卡片
- **奉还卡片** -> 学会魔法**百虫欺天** (t1i11, MP1, 全体吸取HP300) -- 极为强力的全体攻击魔法
- **不给卡片** -> 可交换装备**芦藤雌甲** (t4i13, 避毒) -- 毒瘴林区域有用

**建议**: 如果即将进入毒瘴林区域，芦藤雌甲的避毒效果很实用；但百虫欺天是游戏中最强全体攻击魔法之一(仅消耗1MP)，推荐选择奉还卡片学习魔法。

### 9.2 老王杀/放 (t5i18) -- 不可错过但有后果

**位置**: 石梦城 (t1i37)
**选择**: 放走 / 杀死
- **放走** -> 老王说住石梦城可找他 (后续可再遇)
- **杀死** -> 战斗 (老王 Lv7 HP1600, 金钱2000, 经验1)

**建议**: 放走老王可以获得更多后续互动机会。杀死他获得2000金钱但经验极低(仅1)。

### 9.3 游人钱袋 (t7i1) -- 不可错过但影响收益

**位置**: 建业城 (t1i39)
**选择**: 不给 / 奉还
- **不给** -> 战斗, 赢250文
- **奉还** -> 什么都没有

**建议**: 不给钱袋战斗可以获得250文，但奉还是"善良"的选择。对后续剧情影响不大。

**注意**: 无机乾坤剑是剧情物品，不能装备，但对剧情理解很重要。万能钥匙是一次性消耗品，使用后损坏。

### 12.4 剧情真相总结

**真正的幕后黑手是无机道人(师父)**：

1. 二十年前无机与赤血大战，无机获胜封印赤血，但无机暗中修炼万魔幻化
2. 无机修炼到第7层时需要借用天下民怨戾气，但自己已七分是魔，不能亲自去伏魔洞解除封印
3. 无机利用柳清风解除群魔封印(柳清风是唯一能打开伏魔洞的人)
4. 无机安排朱雀(袁萍芷)在柳清风身边，等待柳清风杀死天道后将柳清风除去
5. 赤血是无机的棋子，在各地制造混乱
6. 天道(五斗米道掌教)知道无机的计划，抢霸王钟是为了对抗
7. 霸王钟对柳清风失效是因为柳清风并非魔族
8. 朱雀被周处点化弃恶向善，在最终时刻揭露真相并自杀
9. 最终柳清风需在三天内赶回三清宫除掉无机，否则无机修炼成万魔幻化第十层(万物幻化为魔，不死之身)将无人能敌
