## ⚠️ 三大核心警告

### 警告1：万能钥匙只有3把

万能钥匙从建业城万锁开处获得，使用一次后**永久损坏**。游戏中共有多个加锁宝箱需要万能钥匙，你只有3次机会。**关键策略**：

| 优先度 | 加锁宝箱位置 | 内含物品 | 是否必须 |
|--------|-------------|----------|----------|
| ★★★ | 白水镇镇长家屋顶 | **虫子卡片** | 三卡片之一 |
| ★★★ | 酆都客栈酒缸 | **小鬼卡片** | 三卡片之一 |
| ★★☆ | 石梦城李虎家东厢房 | 救蔡婆婆女儿（七星灯） | 重要支线 |
| ★★☆ | 观星亭 | 无机乾坤剑（剧情物品） | 剧情向 |
| ★☆☆ | 南北村民房后 | 紫瞳魔灯 | 极强饰品 |
| ★☆☆ | 鹤鸣山洞 | **不点卡片** | 三卡片之一（不需要钥匙） |

> 请至少保证用2把钥匙取虫子卡片和小鬼卡片。南北村的紫瞳魔灯如果钥匙不够可以放弃。

### 警告2：忘忧村蔡婆婆任务链不能断

蔡婆婆任务贯穿半部游戏，一旦错过某个环节就无法补救：

```
蔡婆婆家（忘忧村）→ 蔡婆婆的信 → 建业城万锁开（换万能钥匙）
    → 石梦城李虎家（用金色钥匙救小画家/蔡婆婆女儿）
    → 回蔡婆婆家（奖励七星灯）
```

**如果顺序不对（必须先找东北角屋主→杂货店下屋主→才能进蔡婆婆家），直接进不了蔡婆婆家门！**

### 警告3：三张神秘卡片 —— 核心分歧点

这是游戏中最著名的"愚人"选择。三张卡片在愚人居（天师陵墓后到达）兑换，但**只能三选二**（因为虫子卡片如果给了不点点就没了）：

| 卡片 | 获取地点 | 交给谁 | 获得什么 |
|------|---------|--------|---------|
| 虫子卡片 | 白水镇镇长家屋顶 | 通宵虫 | 魔法：**百虫欺天**（全体吸HP300，MP仅1） |
| 虫子卡片 | 白水镇 | 不点点 | 可购买极品装备（含潮海衣） |
| 小鬼卡片 | 酆都客栈酒缸 | 南方小鬼 | 魔法：**泽伟补命术**（全体HP+1000并解所有异常，MP仅1） |
| 不点卡片 | 鹤鸣山洞宝箱 | 不点点 | 可购买极品装备 |

**推荐方案**：虫子卡片给通宵虫（学百虫欺天）+ 小鬼卡片给南方小鬼（学泽伟补命术）。不点卡片纯粹是购物卡，装备可以后期别处获得。

## 二、伏魔洞取剑

### 路线
```
三清宫 → 百草地 → 竹林山道 → 伏魔山道 → 伏魔洞口 → 伏魔洞
```

### 2.1 8个灯洞（t2i19-t2i26）

依次进入8个灯洞，击败护灯兽（Lv3 HP420 ATK56）。使用**降魔符法**可轻松搞定。每个洞都有宝箱。

> 注意：灯洞6的第三个宝箱可能死机，谨慎操作。

### 2.2 护剑神 BOSS战

伏魔洞深处遭遇护剑神（Lv5 HP1600 ATK100）。**必须练成剑气术后再挑战**。大量投掷青阴君消耗，暗器和药品留给此战。

### 2.3 获得伏魔剑

击败护剑神后获得**伏魔剑**。

## 四、忘忧村

### 4.1 ⚠️ 蔡婆婆任务链（必须严格按顺序）

> **这是整个游戏最容易错过的任务链，一步错就再也进不了蔡婆婆家门。**

**步骤1**：先去找忘忧村**东北角**的房主对话 → 在屋内找到**披风**

**步骤2**：去**杂货店下面**的房子，与主人对话 → 在屋内找到**香袋**

**步骤3**：以上两步做完后，才能进入**村子西北角蔡婆婆**家 → 她会让你去救女儿 → 屋内还有**战狂石**！

### 4.2 村长家 —— 慕容小梅加入

去村子南边的村长家，找到村长，带上慕容小梅。在村长家中找到**丝衣**给小梅装备。

### 4.3 老孟情书

武器店东面房间找到老孟 → 获得**老孟情书**（后续去建业城交给阿军）。

### 4.4 其他搜刮

| 位置 | 物品 |
|------|------|
| 东南角井旁 | 定心符 |
| 杂货店西面 | 茶叶蛋 |
| 愚人居井中 | **罗汉笑**（去瘴气林入口岔路往西） |
| 猎户家旁 | 烤鹿肉 |

### 4.5 武器店

只买**砍刀**！投掷砍刀可伤敌HP-1034，价格便宜，后期打BOSS的利器。

## 五、石梦城

### 5.1 赚钱秘诀

**灵芝草**买入价222元，当铺卖出价444元——这是翻倍赚钱！

### 5.2 李府事件链

**步骤1**：先去李府北面房间找**鲁斧** → 答应帮他夺回芦藤甲

**步骤2**：闯进李府客厅 → 桌上可取**千里飘** → 击败李虎（Lv7 HP2000）→ 获得：
- **芦藤雄甲**（避毒）
- **芦藤雌甲**（避毒）
- **金色钥匙**

**步骤3**：去李府客厅东面的房间 → 用**金色钥匙**开门 → 救出被绑的蔡婆婆女儿

**步骤4**：南面下人房 → 释放老王

### 5.3 ⚠️ 老王选择

```
选项A：放走 → 老王说住石梦城，后续可再遇（推荐）
选项B：杀死 → 战斗（Lv7 HP1600），获得2000金钱
```

> 推荐放走。后续剧情中杀死有额外内容，但放走的后续收益更大。

### 5.4 李府密道

去石梦城老王家中对话 → 他告诉你李府密道入口在关蔡婆婆女儿房间的后方墙壁 → 进入密道搜刮宝物。

### 5.5 其他搜刮

| 位置 | 物品 |
|------|------|
| 李府西南角房间 | 子光金符、寒冰蛙、清凉油、袖里剑 |
| 东南角塔砖 | 穿心镖 |

### 5.6 回忘忧村交任务

穿上芦藤甲回忘忧村 → 去蔡婆婆家 → 她送你**七星灯**！

## 六、建业城

### 6.1 蔡婆婆的信任务

在建业城找到**万锁开** → 交出蔡婆婆的信 → 获得**万能钥匙**！（共3把，一次性使用）

### 6.2 老孟情书任务

找到建业城城西的西向入口房间中的**阿军** → 交出老孟情书 → 获得**金色钥匙**。

### 6.3 游人钱袋

建业城灯柱内拾起钱袋 → 三个游人索要：
- 不给 → 战斗赢250文
- 奉还 → 什么都没有

> 给钱后去客栈找他们战斗→可得**富贵珠**（吉运+99，卖价30000钱！）→ 反复进出客栈刷战斗可快速升级。

### 6.4 武器店

购买大量**弯月刀**——投掷伤害高，后期打天道和赤血的利器。

## 八、白水镇

### 8.1 ⚠️ 获取虫子卡片（极易错过）

**位置**：白水镇西北角镇长家**屋顶**，对准屋顶中间按"输入"键。

> 这是三张神秘卡片之一，没有它愚人居的百虫欺天魔法将永久无法获得！

### 8.2 老宅探索

先去客栈找掌柜 → 镇子南面古宅入口有两个守卫 → 找镇长带领进入 → 老宅南面房间有古怪物品，按"输入"触发机关 → 进入东北角枯井。

### 8.3 摄魂阵破阵

枯井迷宫中找到**摄魂阵**（七大邪阵之一）。八卦方位有8个倒埋孕妇尸体（怨妇幻妖 Lv14-18）。**将倒埋尸体掘出放正**即可破解。救出袁萍芷。

### 8.4 击败赤血

赤血再次出现 → 一个回合投掷弯月刀搞定 → 获得**引路石**（迷宫回起点）。

### 8.5 袁萍芷正式加入

袁萍芷正式加入队伍（Lv9，四象之朱雀）。

## 十二、鹤鸣山

### 12.1 鹤鸣山顶

- 山顶有**嗜血剑**：攻击+250，但灵力-40、防御-30、吉运-30、生命-50，**弊大于利，别用！**
- 杀掉两个小妖后遭遇**天道**（Lv33 HP20000 ATK400）→ 大量投掷弯月刀。

### 12.2 ⚠️ 朱雀/袁萍芷真身揭露（核心剧情）

击败天道后与袁萍芷交手 → 朱雀（袁萍芷）真实身份曝光：四象星君之一，被无机解除封印后安插在柳清风身边 → 但已被周处点化弃恶向善 → 揭露真相：**无机道人才是幕后黑手**，修炼万魔幻化，利用柳清风解除群魔封印 → 朱雀自杀前传授**妙手空空**。

### 12.3 鹤鸣山洞

进入鹤鸣山洞，沿西路走到尽头 → 东面两个宝箱：
- 左边：**不点卡片**（三张神秘卡片之三）
- 右边：**玄冰玉如意**

对着"**替 天 行 道**"四个大字按顺序点击 → **玄武现身** → 击败玄武（Lv34 HP18000 ATK420 DEF700）→ 获得**玄武之精**。

### 12.4 天师陵墓

从四个大字东面进入陵墓迷宫 → 找到天师陵墓入口 → 八卦阵中央的张道陵（天师魂魄 Lv32 HP22000）→ **建议多打几次直到爆出定神珠**（每回合恢复真气10）→ 魂魄升天时带你到忘忧村南的**愚人居**。

## 十三、愚人居

### 13.1 ⚠️ 三张卡片的核心分歧

> 三张卡片对应三个人，但**只能三选二**。卡片有限，选择决定收益。

| 角色 | 给什么卡 | 获得什么 |
|------|----------|---------|
| **南方小鬼** | 小鬼卡片 | **泽伟补命术**——全体HP+1000、解所有异常、MP仅1 |
| **通宵虫** | 虫子卡片 | **百虫欺天**——全体攻击吸HP300、MP仅1 |
| **不点点** | 不点卡片 | 出售极品装备（可买潮海衣） |

> **但如果先找南方小鬼**：他拿走的是你的"不点卡片"而不是"小鬼卡片"——这是著名的愚人陷阱！

### 13.2 推荐方案

**最佳方案**：
1. 先将**虫子卡片**给**通宵虫** → 学**百虫欺天**
2. 再将**小鬼卡片**给**南方小鬼** → 学**泽伟补命术**
3. 不点卡片如果没有了就不用管（不点点那里只能买装备，不是必须的）

> **百虫欺天**和**泽伟补命术**都是MP消耗仅1的神级魔法，不可错过！

### 13.3 潮海衣的获取方式

- 方式1：不点点处购买（用不点卡片或虫子卡片）
- 方式2：四象诛仙阵击败诛仙后有几率掉落
- 无论如何都能获得，不用担心

## 十四、四象诛仙阵破阵

### 14.1 前提条件

回到忘忧村 → 前往三清山 → 途经摩天顶 → 遭遇**四象诛仙阵**。

**必须**：
- 佩戴**天心灯**（每回合恢复HP/MP各30，身法+5）
- 携带四象之精：苍龙、白虎、朱雀、玄武

### 14.2 破阵步骤

依次将四象精魄放入阵四周对应的四大阵门 → 取走阵中央的**混元金斗** → **诛仙现身**（Lv38 HP18000 ATK720 DEF450）→ 击败后有几率掉落**潮海衣**，可存档多打几次。

## 十五、决战无机

### 15.1 三清宫——无机洞

破阵后回三清宫 → 进入无机阁 → 太上老君石像旁 → 面对石像按"输入"键进入**无机洞**。

### 15.2 ⚠️ 最终BOSS

**无机**（Lv44 HP36000 ATK454 DEF760）

投掷2-3把**七星剑**即可击败。无机修炼万魔幻化到第8层，必须尽快解决。

### 15.3 最终战：护剑神

回到伏魔洞 → 伏魔阵中央 → 面对当初拔伏魔剑的位置按"输入" → **超级护剑神**出现（Lv60 HP36000 ATK999 DEF999）→ 最终一战。
